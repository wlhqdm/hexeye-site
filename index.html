PRODUCT (EN — for reviewers)

HexEye is a local Windows helper for League of Legends Hextech Mayhem augment selection. It reads the local League Client (LCU) and Live Client Data in a read-only manner, shows ranked augment prompts on an overlay, and prefers Overwolf Game Events when approved. When GEP is unavailable it uses short, event-gated OCR bursts only (combat default: no continuous capture).

HexEye does not modify game files, inject into game memory for cheats, provide boosting, gambling, or other integrity-breaking features. It is intended as an informational overlay with a free tier.

WHAT IT DOES

在英雄联盟海克斯大乱斗对局中，帮助识别三选一海克斯并展示评级提示。选人阶段可读取候补席做参考排序。

  • 本机 LCU / Live Client Data 只读
  • 优先 Overwolf GEP；未获批时用短突发 OCR 兜底
  • 战斗默认 0Hz 截屏，避免拖垮 FPS
