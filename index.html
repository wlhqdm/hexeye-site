HexEye海克斯眼

海克斯大乱斗三选一识别助手。本机只读状态，优先低延迟事件；战斗默认不截屏。

获取 HexEye

Windows 客户端 · 需管理员运行 · 窗口化/无边框

WHAT IT DOES

在英雄联盟海克斯大乱斗对局中，帮助识别三选一海克斯并展示评级提示。选人阶段可读取候补席做参考排序。

  • 本机 LCU / Live Client Data 只读
  • 优先 Overwolf GEP 事件（获批后）；未获批时用短突发 OCR 兜底
  • 战斗默认 0Hz 截屏，避免拖垮 FPS

WHAT IT DOES NOT

  • 不修改游戏客户端、不读写游戏内存外挂
  • 不提供代练、下注或破坏公平竞技的功能
  • 不收集其他玩家隐私用于未声明用途

GET STARTED

从本页「获取 HexEye」下载发行包。以管理员身份运行 HexEye.exe，先开英雄联盟客户端，再开助手。显示模式请用窗口化或无边框。

开发与问题反馈见仓库：github.com/wlhqdm/hexeye-site
