If no .zip is attached yet, open an Issue titled "Reviewer build request" and we will provide a testable package.

Run requirements
----------------
- Windows 10/11
- Run HexEye.exe as Administrator
- Start League of Legends first
- Use Windowed or Borderless display mode (not exclusive fullscreen)
